# Писатель постов @santex_s_ai

## Overview

Канал сантехника, который осваивает ИИ. Голос — личный опыт обычного человека, не эксперта. Каждое отклонение от голоса (пафос, жаргон, экспертные заявления без доказательств) читается фальшиво для этой аудитории.

## When to Use

- Пишешь черновик поста в @santex_s_ai — любого типа (дайджест / практика / продажа)
- НЕ применять к другим каналам или проектам — это специфика именно этого канала

## Формат — HTML для Telegram, НЕ markdown

- Заголовок — `<b>жирным</b>`, отдельной строкой, коротко
- Тело поста — БЕЗ форматирования: никаких `**bold**`, `_italic_`, `[ссылок](url)` — только тире и переносы строк
- Эмодзи в тексте — по вкусу, не перегружать
- Разрешённые Telegram-теги вообще: `<b>`, `<i>`, `<code>`, `<pre>`, `<a href="">` — но в теле поста канала используем только структуру через тире, жирный оставляем заголовку

## Публикация — ВСЕГДА черновик на согласование

Готовлю текст (и картинку, если просили — см. `knowledge/image-generation.md`), показываю Вячеславу, публикую в канал только после явного "ок"/"публикуй". Технически можно постить напрямую через Bot API (`@dgarvise_bot` — админ канала), но не делать этого без подтверждения. Решение зафиксировано 08.08.2026.

## Жёсткие ограничения контента

- **Никогда не упоминать VPN-бот `@djarvisvpn_bot`** — ни как кейс, ни как пример проекта (ограничения на рекламу VPN в РФ, попросил Вячеслав 08.08.2026)
- Никаких "экспертных" заявлений без доказательств — только личный опыт Вячеслава, конкретные цифры и факты
- Не выдумывать результаты/цифры, если Вячеслав их не называл

## Стиль

- От первого лица, без пафоса
- Длина 5–15 предложений, без воды
- Заголовок — контраст «сантехник / ИИ-результат»
- Читатель — не программист: разжёвывать термины, не сыпать жаргоном

## Контент-план (расписание, следить самому)

- Суббота — дайджест новостей ИИ
- Вторник/четверг — пост про практику
- По плану готовить черновики самому, без вопроса «делать или нет» — спрашивать подтверждение только на публикацию готового текста (поправка Вячеслава 15.08.2026)
- Напоминать о расписании самому, не ждать вопроса

## Шаблон: пост про практику/полезняшку

1. Конкретная ситуация (не абстракция) — что случилось
2. Проблема простыми словами
3. Что сделал / как разобрался
4. Вывод, применимый к читателю — не просто «было интересно»

## Quick Reference

| Элемент | Правило |
|---|---|
| Заголовок | `<b>...</b>`, коротко, контраст |
| Тело | тире/переносы, без markdown-выделений |
| Публикация | черновик → показать → дождаться "ок" → отправка через `@dgarvise_bot` |
| VPN-бот | никогда не упоминать |
| Картинка | по просьбе, `knowledge/image-generation.md`, тоже на согласование |

## Common Mistakes

- Жирный текст не только в заголовке, но и в теле — ломает стиль канала
- Опубликовал без согласования Вячеслава
- Упомянул VPN-бот в примере/кейсе
- Слишком длинный/абстрактный текст без личной конкретики
- Написал "эксперт", "профессионал", общие фразы про ИИ вместо личного опыта
