# Claude Code на Windows — инструкция запуска

**Когда читать:** при вопросах про запуск Claude Code на Windows-компьютере Вячеслава.

---

## Требования

- Node.js v26+ (установлен)
- Claude Code CLI: `npm install -g @anthropic-ai/claude-code` (установлен)
- Свой Hysteria2-туннель (Fornex 213.193.196.125) запущен, локальный SOCKS5/HTTP-прокси на порту 10810 (sing-box, нужен для обхода блокировки Anthropic в РФ)
- Claude Pro подписка (slavin507@gmail.com)

---

## Как запустить (быстрый способ)

Ярлык **Claude Code** на рабочем столе, либо вручную открыть PowerShell и выполнить:
```powershell
& "C:\Users\User\Documents\ИИ и прочее\вайбкодинг\Дмитрий Ледовских-курс\jarvis\scripts\start-claude.ps1"
```
Скрипт сам проверяет туннель на 10810, запускает ярлык `Hysteria2-VPN-Tunnel` из автозагрузки если он не поднят, задаёт прокси и стартует `claude`. Если PowerShell ругается на `ExecutionPolicy` — выполнить `powershell -ExecutionPolicy Bypass -File "...\start-claude.ps1"`.

## Как запустить (вручную, шаг за шагом)

### 1. Проверить туннель
Открыть PowerShell, ввести:
```
Test-NetConnection 127.0.0.1 -Port 10810
```
- `TcpTestSucceeded: True` → туннель поднят, прокси работает, идём дальше
- `TcpTestSucceeded: False` → запустить ярлык `Hysteria2-VPN-Tunnel` (Win+R → `shell:startup` → двойной клик)

### 2. Открыть новый PowerShell
Обязательно отдельное окно (не терминал внутри VS Code — там интерактивный режим не работает).

### 3. Задать прокси и запустить
```powershell
$env:HTTPS_PROXY = "http://127.0.0.1:10810"
$env:HTTP_PROXY = "http://127.0.0.1:10810"
cd "C:\Users\User\Documents\ИИ и прочее\вайбкодинг\Дмитрий Ледовских-курс\jarvis"
claude
```

### 4. Принять предупреждения
- **"Yes, I trust this folder"** → Enter
- **"Bypass Permissions mode"** → выбрать 2 (Yes, I accept) → Enter
- **Fullscreen renderer** → Enter или 2, без разницы

### 5. Работа
Строка `>` внизу — поле ввода. Кликнуть мышкой на неё если не печатает.

## Важные детали

- **VS Code расширение (боковая панель)** — не работает, выдаёт 403. Использовать только CLI.
- **Решение от 2026-06-25:** Вячеслав отказался от VS Code в рабочем процессе с Агентом. VS Code остаётся только как обычный редактор файлов (если нужно посмотреть/поправить код руками), работа с Агентом — только через CLI в отдельном PowerShell.
- **Hysteria2-туннель (Fornex, с 14.08.2026)** — основной способ обхода блокировки. Локальный SOCKS5/HTTP-прокси на порту 10810 (sing-box), работает и для терминала, не только для браузера. Ярлык `Hysteria2-VPN-Tunnel` в автозагрузке (`shell:startup`) поднимает его автоматически при входе в Windows, конфиг `C:\v2rayN\hy2-client\config.json`.
- **Туннель не закрывать** пока работаешь с Claude Code, иначе прокси упадёт (закрыть = снять процесс `sing-box.exe` в диспетчере задач).
- **Прокси** — задавать в каждом новом PowerShell окне (они не сохраняются между сессиями).
- **Bypass Permissions** включён в настройках jarvis проекта — это нормально для автономной работы.
- **VPN Happ** — оставлен как платный запасной вариант (уже установлен, `C:\Program Files\FlyFrogLLC\Happ\Happ.exe`, порт 10809), но по умолчанию не используется — Вячеслав специально ушёл от зависимости от платного VPN 14.08.2026.

## Запасной VPN (если Hysteria2-туннель ляжет)

- **VPN Happ (платный)** — порт 10809, тот же принцип (`$env:HTTPS_PROXY = "http://127.0.0.1:10809"`). Использовать только если свой туннель Fornex недоступен и нужно починить срочно.
- 2026-07-13/07-19: пробовали ProtonVPN Plus (Stealth) как бесплатную от него независимую альтернативу — не пробивает блокировку ни с компьютера, ни с телефона, вариант закрыт
- **История:** личный туннель раньше стоял на TimeWeb (64.188.57.249) — 14.08.2026 обнаружили, что провайдер заблокировал этот IP целиком (не проходил даже SSH напрямую, не только Hysteria2/UDP). Переехали на Fornex (213.193.196.125, IP пока чистый) — если и его когда-нибудь заблокируют, тот же rebuild-процесс: новый сервер + `bash <(curl -fsSL https://get.hy2.sh/)` + self-signed сертификат + `/etc/hysteria/config.yaml` (auth password + obfs salamander)

## Если что-то не работает

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `ECONNREFUSED` | Happ не запущен/не подключён | Открыть Happ, подключиться к VPN |
| `ERR_BAD_REQUEST` | Прокси не задан явно | Задать `$env:HTTPS_PROXY` |
| `UnsupportedProxyProtocol` | Прокси указан как socks5:// | Использовать http:// |
| Claude Code сразу закрывается | VS Code terminal | Открыть отдельный PowerShell |
