# Репозиторий 345+ скиллов для Claude Code

> Источник: промо-страница «Команда спецов из Claude Code» (подарок ко дню рождения «Нейробазы», 19–20.08.2026), сохранена как `Команда спецов из Claude Code.mhtml`.

Репозиторий: **https://github.com/alirezarezvani/claude-skills**

Заявлено на лендинге: 345+ скиллов, 30+ направлений. По факту в репозитории (проверено 20.08.2026 через WebFetch): **362 навыка** (число расходится по разным местам README) + 30+ агент-персон + 70+ кастомных команд + 741 шаблон/чеклист, под 13 платформ (Claude Code, OpenAI Codex, Gemini CLI, Cursor, Hermes Agent и др.). 18 категорий: инженерия, маркетинг, исследования, C-level, продукт, финансы, compliance, бизнес-операции. Каждый навык — папка с `SKILL.md` + опционально `scripts/`, `references/`, `assets/`.

**Метрики (20.08.2026):** 24.7k звёзд, 3.5k форков, 1286 коммитов, лицензия MIT. Реальный, активно поддерживаемый проект, не пустышка.

**Установка:**
- Claude Code marketplace: `/plugin install engineering-skills@claude-code-skills`
- Ручное клонирование + копирование нужных папок в `~/.claude/skills/`
- Конверсия под другой инструмент: `./scripts/convert.sh --tool all`

**Риск:** масштаб (362 скилла от сообщества) требует проверки каждого — в репо даже есть отдельный `skill-security-auditor` для аудита чужих скиллов. **Не ставить всё скопом поверх уже настроенных скиллов Jarvis (`.claude/skills/`) и плагина Superpowers** — смотреть точечно, когда понадобится конкретная категория под новую задачу/субагента, и проверять SKILL.md перед установкой.

**Решение Вячеслава 20.08.2026: держим только как справочник, массовую установку не делаем.** Текущий набор (4 скилла + Superpowers) достаточен. Открывать репо точечно под конкретный будущий скилл — например, когда появится следующая роль нейрозавода (см. [30-ai-sotrudnikov.md](30-ai-sotrudnikov.md)).
