Заявлено: 345+ скиллов, 30+ направлений (маркетинг, разработка, дизайн, аналитика, кибербезопасность, базы данных, копирайтинг и т.д.), структурировано по категориям, установка каждого скилла — одна команда в терминал (шаблон команды на самом лендинге не был виден в статике, смотреть в README репозитория).

Прежде чем ставить скиллы оттуда в этот проект — открыть репозиторий, посмотреть на реальное качество/актуальность и на лицензию, не тащить бездумно поверх уже настроенных скиллов Jarvis (`.claude/skills/`) и плагина Superpowers.
