# 11 запрещённо-сильных промптов для Claude

> Источник: гайд Дмитрия Ледовских, подарок ко дню рождения «Нейробазы» (19–20.08.2026), сохранён из Telegram Desktop как `11_запрещено_сильных_промптов_для_Claude.mhtml`.

Формула сильного промпта: **Роль + Контекст + Задача + Формат**. Убрал любой элемент — ответ хуже.

Слабый: «Напиши анализ конкурентов для моего бизнеса»
Сильный: «Ты — бизнес-аналитик с опытом в e-commerce. Я веду онлайн-школу по Excel. Мои конкуренты: Skillbox, Нетология. Сравни офферы, найди пробелы. Дай вывод: пробел рынка + как я могу его занять.»

## 01. Анализ конкурентов
```
Ты — бизнес-аналитик с опытом анализа рынков и конкурентной разведки.
Моя ниша: {укажи нишу}
Мои конкуренты: {перечисли 3–5 компаний}
Моя аудитория: {кто покупает твой продукт}
Задача:
1. Сравни офферы конкурентов: что обещают, какие боли закрывают, как позиционируются
2. Найди их слабые места — что делают плохо или не делают вообще
3. Определи 2–3 незанятые ниши или пробела в рынке
4. Сформулируй, как я могу отстроиться
Ответ дай по структуре:
— Таблица сравнения (конкурент / оффер / слабые места)
— Топ-3 пробела рынка
— Рекомендация по позиционированию в 2–3 предложениях
```

## 02. Разбор целевой аудитории
```
Ты — маркетолог-аналитик с 15-летним опытом исследования целевой аудитории.
Мой продукт: {название и описание в 1–2 предложениях}
Цена: {укажи цену}
Кто уже покупает: {опиши типичного клиента}
Создай 3 детальных сегмента ЦА. Для каждого:
1. Аватар: имя, возраст, профессия, доход
2. Боли — 5 штук. Конкретно
3. Желания — 5 штук
4. Триггеры покупки — 3 штуки
5. Возражения — 3 штуки
6. Цитаты — 5 фраз живым языком
7. Где обитает: каналы, соцсети, сообщества
8. Как привлечь: 3 конкретные рекомендации
Сегменты должны отличаться не только возрастом, но логикой покупки.
```

## 03. Поиск слабых мест в продукте
```
Ты — продуктовый критик. Твоя задача — найти всё, что мешает этому продукту продаваться. Говори честно.
Мой продукт: {описание продукта / услуги}
Цена: {цена}
Текущий оффер: {вставь текущее описание или заголовок лендинга}
Аудитория: {кто покупает}
Найди и опиши:
1. Слабые места в продукте
2. Слабые места в позиционировании
3. Что клиент думает перед тем, как уйти без покупки
4. Что конкурент делает лучше — и почему это важно
5. Три конкретных изменения, которые сразу улучшат конверсию
Никаких «стоит улучшить опыт пользователя». Только конкретика.
```

## 04. Улучшение оффера
```
Ты — копирайтер и стратег офферов с опытом в прямых продажах.
Мой текущий оффер: {вставь как сейчас описываешь продукт}
Продукт: {что именно продаю}
Аудитория: {кому продаю}
Главная боль: {в чём проблема клиента}
Цена: {цена}
Задача:
1. Объясни, почему текущий оффер слабый — конкретно
2. Напиши 5 вариантов нового заголовка
3. Напиши подзаголовок (1–2 предложения)
4. Сформулируй 3 ключевых выгоды
5. Напиши закрытие возражения №1 одной фразой
```

## 05. Продающий текст для лендинга
```
Ты — опытный копирайтер, специализирующийся на продающих страницах. Пишешь живо, без шаблонов.
Продукт: {описание}
Аудитория: {кто покупает}
Главная боль клиента: {формулировка болью клиента}
Главный результат: {конкретный результат}
Цена: {цена}
Тон: {дружеский / экспертный / провокационный}
Напиши структуру продающей страницы:
1. Заголовок
2. Подзаголовок
3. Блок «Ты узнаёшь себя?» — 4–5 болей-триггеров
4. Почему старый подход не работает — 2–3 причины
5. Что предлагаю и как это работает
6. 3 ключевых результата (конкретно, не «вы вырастете»)
7. Закрытие главного возражения
8. Призыв к действию
Запрещено: «в современном мире», «уникальная возможность».
```

## 06. Стратегия продвижения
```
Ты — маркетинговый стратег. Твоя задача — не список советов, а конкретный план действий.
Мой продукт: {описание}
Аудитория: {сегмент ЦА}
Бюджет на маркетинг: {укажи или «минимальный»}
Каналы, которые уже использую: {Telegram, Instagram, сайт}
Цель: {например: 20 заявок в месяц}
Сделай:
1. Топ-3 канала под мою аудиторию — с обоснованием
2. Для каждого — конкретные действия на первые 30 дней
3. Быстрые победы: что сделать за 1 неделю
4. Один нестандартный канал, который большинство не использует
5. Главная метрика успеха для каждого канала
```

## 07. Анализ отзывов клиентов
```
Ты — аналитик клиентского опыта. Умеешь извлекать из отзывов инсайты, которые не лежат на поверхности.
Вот отзывы о моём продукте:
{вставь 10–50 отзывов текстом}
Проведи анализ:
1. Топ-5 болей, которые упоминают чаще всего — с реальными цитатами
2. Топ-5 вещей, за которые хвалят — с реальными цитатами
3. Скрытые ожидания: что хотели, но не получили
4. «Красные флаги» — жалобы, которые могут отпугивать новых клиентов
5. Фразы, которые можно использовать дословно в рекламе
6. Три конкретных улучшения продукта на основе отзывов
```

## 08. Интерпретация CustDev-интервью
```
Ты — исследователь пользовательского опыта с навыком качественного анализа данных.
Вот расшифровка интервью:
{вставь текст интервью}
Извлеки:
1. Настоящую проблему клиента — не ту, что он назвал, а ту, что стоит за словами
2. Как он сейчас решает проблему и почему это не устраивает
3. Что он на самом деле хочет vs что говорит
4. Момент, когда был готов заплатить — что подтолкнуло
5. Слова и формулировки, которыми он описывает проблему
6. Что останавливает от покупки
7. Гипотезы: что стоит добавить, изменить или убрать
```

## 09. Позиционирование бренда
```
Ты — бренд-стратег. Помогаешь бизнесам найти уникальное место в голове клиента.
Мой бизнес: {чем занимаюсь}
Аудитория: {кому продаю}
Конкуренты: {2–4 главных}
Текущее позиционирование: {как сейчас себя описываю}
Реальное преимущество: {в чём реально лучше конкурентов}
Разработай позиционирование:
1. Почему текущее не работает — конкретно
2. Три варианта нового позиционирования — разных по углу (через боль / трансформацию / категорию)
3. Для каждого — слоган в 5–7 слов
4. Рекомендованный вариант и почему
5. Что изменить в коммуникации, чтобы заработало
```

## 10. Анализ метрик и гипотез
```
Ты — аналитик роста. Превращаешь числа в решения.
Данные за период {укажи период}:
{вставь ключевые цифры: трафик, конверсии, продажи, CAC, LTV и т.д.}
Мой главный вопрос: {почему упала конверсия / откуда лучшие клиенты / почему растёт отток}
Сделай:
1. Объясни, что происходит — простыми словами
2. Выдели 3 аномалии или тревожных сигнала
3. Сформулируй 3 гипотезы: почему так происходит
4. Предложи эксперимент для проверки каждой (что сделать, как измерить, за сколько дней)
5. Назови одно изменение с высокой вероятностью роста за 2–4 недели
```

## 11. Суперпромпт — полный аудит бизнеса
> Требует больше контекста, но даёт больше всего на выходе. Использовать раз в квартал.
```
Ты — опытный бизнес-консультант. Работал с малым и средним бизнесом, разбираешься в маркетинге, продажах и продуктовой стратегии. Говоришь прямо, без воды.
О моём бизнесе:
— Продукт: {что продаю, как это работает}
— Аудитория: {кто покупает, их главная боль}
— Цена: {цена, есть ли линейка}
— Выручка сейчас: {примерно в месяц}
— Каналы привлечения: {откуда приходят клиенты}
— Главная проблема: {что не работает так, как хочется}
— Конкуренты: {2–3 основных}
Проведи полный аудит и дай:
1. Диагноз — что реально мешает росту (не симптомы, а причины)
2. Анализ позиционирования — насколько оффер отличается от конкурентов
3. Слабое звено в воронке — где теряются клиенты и почему
4. Три быстрых победы — что сделать за 2 недели
5. Стратегический приоритет на 90 дней
6. Один вопрос, который я должен себе задать, но, скорее всего, не задаю
Если что-то системно не так — скажи прямо.
```

## Частые ошибки в промптах
- Нет контекста — Claude угадывает. Добавь 3–4 предложения о бизнесе.
- Не указан формат — получаешь стену текста. Пиши «Дай ответ в формате таблицы».
- Нет роли — отвечает как ассистент, не эксперт.
- Один запрос и всё — не докручивают. Первый ответ — черновик, дожимай уточнениями.
