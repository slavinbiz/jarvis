## VPN-бот / s-ui — критичное правило

- **НИКОГДА не писать JSON в blob-колонки s-ui (`options`, `out_json`, `config` в таблицах `inbounds`/`clients`) через сырой `sqlite3` без `CAST(... AS BLOB)`** — иначе Go-driver падает на `sql: Scan error ... unsupported Scan, storing driver.Value type string into type *json.RawMessage`, ядро Hysteria2 не стартует, VPN лежит у всех (личный + все клиенты бота). Ломалось так дважды (1 и 2 июля 2026) — подробности knowledge/s-ui-sqlite-editing.md
- Меняя конфиг Hysteria2 (obfs и т.п.) на сервере — обновлять ВСЕ клиенты одновременно (свой Windows-туннель + шаблон клиента VPN-бота), иначе рвёт текущие подключения. Параллельно Jarvis работает ещё через Telegram-бота на Fornex — та сессия тоже может лезть в TimeWeb/s-ui, перед правками VPN-инфры сверяться со свежими дневниками memory/

## SSH-доступ к серверам

- На Windows-машине есть ключ `~/.ssh/id_ed25519` — прямой root-доступ без пароля на TimeWeb `64.188.57.249` и Fornex `213.193.196.125`. Beget `91.193.25.237` потерян (см. выше). Просто `ssh -i ~/.ssh/id_ed25519 root@<ip>`.
- **Первое подключение к новому серверу без ключа:** через `plink.exe` (PuTTY, есть на машине) с паролем, добавить свой pubkey в `authorized_keys`, дальше обычный ssh без пароля. `plink -ssh -batch -pw "<пароль>" -hostkey "<fingerprint>" root@<ip> "..."` — `-hostkey` нужен, чтобы обойти интерактивное подтверждение host key в batch-режиме.

## Ключевые решения (Windows)

- **Claude Code на Windows:** запускать из отдельного PowerShell (не VS Code terminal), с явным `$env:HTTPS_PROXY = "http://127.0.0.1:10810"`, из папки jarvis. С 14.08.2026 обход блокировки через собственный Hysteria2-туннель на Fornex (не платный Happ) — туннель поднимается автоматически ярлыком в автозагрузке, локальный прокси на порту 10810. Happ остаётся как платный запасной вариант (порт 10809).
- **Быстрый запуск:** ярлык «Claude Code» на рабочем столе → `scripts/start-claude.ps1` (сам поднимает туннель, выставляет прокси, стартует `claude`).
- **VS Code расширение Claude Code:** не работает (403 geo-block). Только CLI.
- **`.ps1` с кириллицей:** сохранять как UTF-8 с BOM, иначе Windows PowerShell 5.1 ломает русские буквы в пути/тексте и скрипт не парсится.
