### Реализовано (закрывает TODO выше)
Через superpowers:brainstorming (bounded) согласовали дизайн: триггер — тот же разворотный паттерн ещё раз на том же памп/дамп-рывке; лимит 2 попытки всего; перезаход и на реальном стопе, и на отменённой лимитке без входа (не на истечении окна наблюдения без единого паттерна — это другой случай).

- `MAX_ENTRY_ATTEMPTS = 2`, новый `build_retry_watch()` — пересобирает `pin_bar_watches` для повторной попытки: экстремум НЕ сбрасывается (продолжает копиться от худшей точки за всё время, иначе инвалидация будет неверной), окно свечей на поиск паттерна — с нуля, памп-контекст (pump_pct/window/target_price) переносится как есть

- Второй заход проходит тот же гейт R:R ≥ 3.0, ничего не форсируется
- `fmt_entry_caption` — новый параметр `attempt`, при attempt>1 в сообщение о входе добавляется строка «🔁 Повторная попытка (N/2)»
- Проверил изолированным тестом: build_retry_watch корректно переносит контекст и экстремум между попытками, граница MAX_ENTRY_ATTEMPTS=2 не даёт 3-й попытки; caption с attempt=2 рендерится правильно
