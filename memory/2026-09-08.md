### Решения
- **Разворотная стратегия, не следование за трендом.** После памп/дамп-рывка вход берём ПРОТИВ движения (шорт после пампа по медвежьему паттерну, лонг после дампа по бычьему) — подтвердил Вячеслав явно, дважды (направление входа + жёсткость дивергенции как условия)
- Дивергенция RSI — обязательный гейт для входа, не просто пометка в сообщении
- Тейк = уровень начала движения (обычно докатывает туда, 3-5%, иногда больше — дальше на усмотрение Вячеслава, не автоматизируем)
- **Старые данные (1м-эра, 37-38% винрейт) стёрты безвозвратно** — новую статистику собираем с нуля на 5м-таймфрейме с полной новой стратегией входа, сравнивать старое с новым не с чем
