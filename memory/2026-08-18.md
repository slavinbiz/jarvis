# 2026-08-18

## Сессия 1 (Windows, 09:xx)
Тема: голосовые Джарвису в Telegram не распознаются

### Сделано
- Диагностировал через systematic-debugging: root cause — после переезда с Beget на Fornex (08.08) распознавалку голоса не перенесли вообще. В `/home/agent/.agent/.env` не было ни `DEEPGRAM_API_KEY`, ни установленного Whisper — бот молча уходил в fallback-сообщение "Не получилось распознать" (без логов, поэтому в journalctl ничего не было видно)
- Попытался поставить Whisper локально (`apt install ffmpeg` — ок) — pip не был установлен, поставил `python3-pip`, запустил `pip install openai-whisper`
- **Инцидент:** pip начал тянуть полный GPU/CUDA-набор torch (nvidia-cuda-*, triton, ~сотни МБ) на сервере без GPU. Диск Fornex — всего 9.8GB, свободно было 5.4GB → скатилось до 702MB (93% занято) прежде чем заметил и убил процесс (`pkill -9 -f pip`). Почистил `pip cache purge` (+455MB) и `apt clean` — вернул 1.3GB свободных
- Вячеслав выбрал вместо Whisper — Deepgram (не грузит диск сервера). Зарегистрировался, прислал API-ключ, вписал в `.env`, перезапустил `agent-bot` — сервис активен, ключ подхвачен

### Решения
- **Whisper на Fornex НЕ ставим** — диск слишком маленький (9.8GB) для torch+CUDA зависимостей, риск уронить продакшен-бота на этом же сервере. Deepgram — постоянное решение для голосовых
- Если когда-то понадобится офлайн-распознавание — делать на отдельном сервере с бóльшим диском, не на Fornex
