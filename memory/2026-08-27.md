### Решения
- `.graphify/` не коммитим и не синкаем — это разовый локальный анализ, не часть DNA-архитектуры агента
- Полное лейблирование сообществ/описаний узлов отложено — можно доделать по запросу (`graphify describe .` + `graphify label .` + `graphify update .`, ~2 прохода заполнения batch-JSON)
- **Больше не использовать `graphify update`/`--watch` для довыгрузки кода** — тащит git-лог как мусорные узлы без возможности отключить. Для инкрементальных обновлений — тот же ручной пайплайн detect→extract→build, которым граф строился первый раз
