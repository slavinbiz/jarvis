### Решения
- При правке .ps1-скриптов с кириллицей на этой машине — файл должен быть в UTF-8 **с BOM**, иначе PowerShell 5.1 читает кириллицу как другую кодировку и либо ломает парсинг, либо не находит файл по литеральному пути (споткнулся на этом дважды за сессию — на дубле fb2 и на Word-огрызках). Уже было записано в MEMORY.md применительно к автозагрузочным скриптам, теперь подтверждено и для одноразовых scratch-скриптов
- Cyrillic-имена файлов иногда не матчатся по литеральному пути между bash/PowerShell из-за разной Unicode-нормализации (NFC/NFD) — рабочий обход: искать файл через `Get-ChildItem -Filter` с ASCII-частью паттерна (например `'*(2).fb2'`) вместо литеральной строки с кириллицей
